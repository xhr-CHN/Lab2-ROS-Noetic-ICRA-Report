# Source Snapshot Notes

The experiment used the upstream repository below at commit `609f31f`:

https://github.com/MIT-SPARK/VNAV-labs

That commit is the ROS1/catkin-compatible version used for the successful build. The repository tip was ROS2/`ament_cmake` and was rejected by catkin.

The host Windows environment could not clone GitHub during final packaging because the connection to `github.com:443` was unavailable. Therefore this archive includes the verified modified source files under `report/code/` and records the exact upstream provenance rather than pretending to contain an unverified full clone.
